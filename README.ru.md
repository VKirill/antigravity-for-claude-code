## Что это такое?

**Antigravity for Claude Code** — это MCP-сервер, который работает как мост между **Claude Code** (через тестовый оркестратор `dev-orchestrator-test`) и консольным клиентом **Antigravity CLI** (`agy`) на базе Google Gemini.

Вместо запуска медленных встроенных субагентов для тяжелых задач программирования Claude Code передает работу утилите `agy` (на базе Gemini 3.5 Flash/Pro). Она загружает локальные правила и скиллы (например, `coder-craft` и `orchestrator-workflow`), аккуратно правит файлы, гоняет тесты и возвращает готовый результат.

Инструмент также добавляет в ваш терминал автоматические **дебаты между ИИ-агентами**, быстрый **аудит кода** и выдачу **технических советов**.

## Структура репозитория

* `dist/` — скомпилированные файлы MCP-сервера.
* `examples/` — примеры подключения на TypeScript, Python, Go и Bash.
* `agents/` — файл конфигурации кастомного агента `dev-orchestrator-test.md`.

## Перенесенные скиллы (`/skills`)

Эти папки содержат инструкции, которые помогают Gemini работать как профессиональный разработчик или архитектор:
* **Базовые правила**: `coder-craft` (чистый код, хирургические правки, контроль лимитов строк), `karpathy-guidelines` (принципы Андрея Карпатого: простота кода, отказ от лишних абстракций).
* **Рабочий процесс**: `orchestrator-workflow` (парсинг YAML-контрактов, взаимодействие с БД, автоматическое восстановление), `claude-code` (стандартные паттерны вызовов).
* **Фронтенд-стек**: `frontend-craft`, `css-architecture-2026`, `design-system-2026`, `ux-craft-2026`, `web-animation-router`, `webgl-creative-2026`, `svg-canvas-craft`, `motion-spec-handoff`, `web-qa-2026` (инспекция a11y, Lighthouse, адаптивность).
* **Тестирование и редактура**: `pytest`, `vitest`, `ru-text-quick` (инфостиль, правила русской типографики, запрет ИИ-клише).

## Доступные MCP-инструменты

Сервер предоставляет следующие инструменты для Claude Code:
* `discuss_with_antigravity` — ведение многошагового диалога или обсуждения с Antigravity. Автоматически извлекает ID задачи (например, `id: TASK-NNN`) из текста промпта для привязки контекста сессии.
* `reset_antigravity_session` — сброс истории активной сессии обсуждения в памяти.
* `run_debate_deliberation` — запуск автономных дебатов между специализированными ИИ-персонажами (Оптимист, Скептик, Соглашатель, Хейтер) с генерацией итогового ADR.
* `run_interactive_debate` — интерактивные дебаты, где пользователь выступает в роли Судьи/Архитектора, направляя ход обсуждения репликами, с последующей финализацией в ADR.
* `review_code_changes` — проведение аудита изменений кода (code review) на русском языке (поиск багов, проверка безопасности, чистоты кода).
* `get_programming_advice` — получение быстрого точечного совета по коду или архитектуре для конкретной проблемы.
* `get_debate_receipt` — генерация структурированного «чека дебатов» (Markdown-отчета), содержащего роли участников, их тезисы (claims), аргументы (evidence), отвергнутые альтернативы, измененные файлы и данные аудита безопасности (сработавшие защитные хуки).

## Установка и настройка

### 1. Сборка MCP-сервера
Склонируйте репозиторий, установите зависимости и соберите проект:
```bash
cd ~/tools/antigravity-for-claude-code
npm install
npm run build
```

### 2. Подключение сервера к Claude Code
Добавьте этот сервер в ваш глобальный файл настроек `~/.claude.json`:
```json
{
  "mcpServers": {
    "antigravity": {
      "command": "node",
      "args": ["/home/ubuntu/tools/antigravity-for-claude-code/dist/index.js"]
    }
  }
}
```

### 3. Настройка оркестратора
Скопируйте кастомного агента оркестратора из папки репозитория в конфигурацию Claude Code:
```bash
mkdir -p ~/.claude/agents
cp agents/dev-orchestrator-test.md ~/.claude/agents/
```
Теперь вы можете запустить его командой:
```bash
claude --agent dev-orchestrator-test
```
Оркестратор автоматически настроен на 100% замену всех внутренних субагентов (кодеров, верификаторов тестов, UI, платежей, безопасности и дебаггеров) на вызовы Antigravity с соответствующими ролями и промптами лучших практик 2026 года.

### 4. Настройка скиллов разработчика
Чтобы Antigravity (`agy`) мог использовать перенесенные скиллы, скопируйте содержимое папки `skills` в глобальную директорию скиллов Antigravity:
```bash
mkdir -p ~/.gemini/antigravity/skills
cp -r skills/* ~/.gemini/antigravity/skills/
```

### 5. Настройка защитных хуков качества (Рекомендуется)
Чтобы агент не использовал обходные пути (не писал `@ts-ignore` или инлайновые HEX-стили в Vue/CSS файлах), установите глобальные хуки валидации:
```bash
npm run install-hooks
```
Этот скрипт сделает файл валидатора исполняемым и автоматически пропишет корректный абсолютный путь к вашему проекту в глобальный конфигурационный файл `~/.gemini/antigravity-cli/hooks.json`.

## Кейс из практики (Case Study)

### Как автор проекта (Кирилл) использует этот инструмент в работе:

#### 1. Планирование и контракты
При решении сложных задач Кирилл запускает тестовый оркестратор через команду `ccdt`. Тот оценивает сложность, декомпозирует задачу и записывает план в локальную базу данных `.claude/orchestrator.db` в виде YAML-контрактов.

#### 2. Передача работы в Antigravity
Оркестратор видит задачи, назначенные исполнителю `worker-coder`, и перенаправляет их в инструмент `discuss_with_antigravity`. 

#### 3. Изолированная разработка в `agy`
Antigravity берет задачу и обрабатывает ее в соответствии со скиллом `coder-craft`:
1. Создает локальный git-worktree (например, в папке `.worktrees/feat-auth-fix/`) и делает туда симлинк на общую базу `.claude/orchestrator.db`.
2. Вносит точечные правки, соблюдая стиль окружающего кода. 
3. Не выходит за лимиты строк (до 250 строк на файл для TS).

#### 4. Тестирование и деплой
После завершения правок оркестратор запускает тесты (например, `bun test`). 
* Если тесты прошли успешно: оркестратор сливает изменения в ветку `main`, отправляет код на GitHub, собирает проект и перезапускает процессы в PM2 (`pm2 reload`).
* Если тесты упали: запускается цикл самовосстановления — ошибки передаются обратно в Gemini для исправления.
