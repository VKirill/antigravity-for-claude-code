CASE STUDY

How Kirill Vechkasov Uses This Setup For Fast Iteration

A deep-dive walkthrough of the daily workflow of the author, proving the viability of Gemini-based coder agents running inside Claude Code orchestration environments.

01

Task Planning in SQLite

Kirill launches the orchestrator via the alias ccdt. The PM agent assesses task complexity, drafts YAML contracts, and writes them to .claude/orchestrator.db.

02

Task Dispatch to Antigravity CLI

Instead of spawning slow subagents, the orchestrator issues a call to discuss_with_antigravity. The MCP server runs agy in a dedicated, isolated sub-session.

03

Skills Injection & Coder-Craft Enforcement

Antigravity loads the coder-craft skill. It enforces rigid guidelines: writing clean code, keeping files below 250 lines, and executing edits surgical-style without refactoring side code.

04

Automated Testing & Rollbacks

Once edits are done, local verifiers run the test suite. If green, the change is merged to main and deployed with PM2. If red, the errors are piped back to Gemini for self-correction.
