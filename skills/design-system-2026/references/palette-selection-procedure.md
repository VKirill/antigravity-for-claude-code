# palette-selection-procedure.md — как агент ОСМЫСЛЕННО выбирает дизайн и пишет его в проект

> Обязательная процедура для `worker-brand-token-designer` (и `site-architect` при оркестрации).
> Превращает «импровизацию по вкусу» в **выбор из выверенного меню + обоснование + запись в контракт**.
> Код (HTML/CSS) по-прежнему пишется с нуля — меняется лишь то, ИЗ ЧЕГО агент решает.

## Два слоя (не путать)

- **Библиотека** (generic, переиспользуется) — в этом же скилле `design-system-2026`:
  `palette-schemes.md` (палитры), `type-pairings.md` (шрифты), `palette-selection-procedure.md` (этот файл).
  Структура блоков/страниц → `ux-craft-2026` (`ia_page_blueprint_kb.md`); моушен → `web-animation-router`
  + `motion-spec-handoff`. (Не плодим новые скиллы — расширяем references существующих.)
- **Проект** (`docs/plans/<slug>/`, выбор под один бизнес): `DESIGN.md` (токены), `art-direction.md`
  (стиль + почему), `motion-spec.yaml` (моушен), `pages.yaml`/`ia.md` (структура).

Библиотека = меню. Проектные файлы = записанный выбор. Агент не изобретает цвета — **выбирает и инстанцирует**.

## Процедура SELECT → JUSTIFY → INSTANTIATE (6 шагов)

**Вход:** `brief.md`, `audience-portrait.md`, `competitors.md`, `strategy.md`.

1. **Определи настроение.** Из ЦА + тона бренда (strategy) + чем берут конкуренты → 2–4 тега mood
   (напр. «спокойный, прибрежный, доверие»). Зафиксируй, ПОЧЕМУ (1–2 строки от ЦА/конкурентов).
2. **Выбери палитру.** Найди в `palette-schemes.md` запись с пересечением по `mood`/`industry`/`use-when`.
   Бери ОДНУ. Проверь `avoid-when` — не противоречит ли. Запиши ID (напр. `PAL-001`).
3. **Выбери шрифтовую пару.** Из `type-pairings.md` по характеру (быстрый ключ внизу файла). ОДНУ. ID (`TYP-001`).
4. **Дифференцируйся, не ломая.** Сверься с `competitors.md`: если все конкуренты в одной гамме —
   выбранная палитра должна отличаться (это и есть «use-when» большинства записей). Если палитра
   совпала с конкурентами — возьми соседнюю по настроению. Не добавляй «свои» цвета — это путь к супу.
5. **Проверь анти-суп правило.** Финальный набор хром-акцентов = максимум **1 тёплый + 1 холодный +
   функциональный CTA**. Если палитра + бренд-требования дают больше — урезай до ролей (что декор, что CTA).
   CTA-конфликт (как teal+green+amber в v3) решается: либо CTA в семье primary, либо один тёплый акцент
   как буфер, либо изоляция CTA только на кнопки.
6. **Инстанцируй в контракт.** Скопируй роли выбранной палитры в `DESIGN.md` как `:root` токены
   (имена — раздел «Token contract» ниже) + строку происхождения `palette: <ID>`; шрифты → `--font-display`/
   `--font-text` + флюид-шкала из `type-pairings.md`. Обоснование (mood + почему + ID палитры/пары) →
   `art-direction.md` (или отдельный `design-rationale.md`). Моушен → `motion-spec.yaml` (пресет, когда появится).

## Token contract (имена, которые читает craft-gate и пишет агент)

Палитра инстанцируется ровно в эти кастом-проперти (роль → токен):

```css
:root {
  --color-bg:           /* bg */;
  --color-surface:      /* surface */;
  --color-ink:          /* ink — весь текст */;
  --color-primary:      /* primary — голос бренда */;
  --color-primary-dark: /* primary-dark — цены/hover */;
  --accent:             /* accent — ТОЛЬКО декор/крупное */;
  --color-cta:          /* cta — ТОЛЬКО кнопки */;
  --color-border:       /* border */;
  --font-display:       /* display из пары */;
  --font-text:          /* text из пары */;
}
```

Правило: блоки рисуют ТОЛЬКО через `var(--…)` — смена палитры = смена значений, перекрашивается всё.

## Превращение СЫРЬЯ в новую запись каталога (когда нужна палитра, которой нет)

Не клади сырьё с ColorHunt/Coolors напрямую — прогони через `tools/build-palette-schemes.mjs`:
1. Возьми сырьё (свотчи). 2. Назначь роли + дострой нейтрали/ink/surface (сырьё их почти не содержит).
3. Добавь объект в массив `PALETTES` (роли + mood/use-when/do-dont/why). 4. Запусти генератор —
он посчитает OKLCH + контраст WCAG и впишет вердикты (AA / AA-lg / decor-only). 5. Каталог обновлён, значения точны.

## Definition of done

- В `DESIGN.md` есть `:root` с 8 токенами цвета + 2 шрифта + строка `palette: <ID>`; все пары текст/фон ≥ AA (или помечены decor-only).
- В `art-direction.md`/`design-rationale.md` записано: mood, выбранные `PAL-xxx`/`TYP-xxx`, и ПОЧЕМУ (от ЦА/конкурентов).
- Анти-суп правило соблюдено (≤2 хром-акцента + CTA по роли).
