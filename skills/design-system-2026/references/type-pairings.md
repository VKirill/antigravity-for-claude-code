# type-pairings.md — выверенные шрифтовые пары (библиотечный слой)

> Меню пар **display + text**. Агент выбирает ОДНУ под характер бренда (см. `transform-procedure.md`)
> и инстанцирует в `DESIGN.md` как `--font-display` / `--font-text` + флюид-шкалу.
> Все шрифты — Google Fonts / Fontsource (бесплатные, с латиницей+кириллицей где отмечено).
>
> Правила, общие для всех пар:
> - **display** — ТОЛЬКО заголовки (h1–h2/display). Никогда для body.
> - **text** — body, labels, цены (с `tabular-nums`), caption, кнопки.
> - Шкала — флюид `clamp()`, **≥5 ступеней** (display, h1, h2, body-lg, body, caption).
> - Body ≥16px (анти-зум iOS). Не более 2 начертаний на экран в одной иерархии.
> - Контраст характера: один выразительный (display) + один нейтральный (text). Два выразительных = шум.

## Флюид-шкала (шаблон, инстанцируется в DESIGN.md)

```css
:root {
  --step--1: clamp(0.83rem, 0.79rem + 0.18vw, 0.94rem);   /* caption */
  --step-0:  clamp(1.00rem, 0.93rem + 0.30vw, 1.13rem);   /* body */
  --step-1:  clamp(1.20rem, 1.09rem + 0.50vw, 1.50rem);   /* body-lg / h3 */
  --step-2:  clamp(1.44rem, 1.27rem + 0.80vw, 2.00rem);   /* h2 */
  --step-3:  clamp(1.73rem, 1.46rem + 1.30vw, 2.67rem);   /* h1 */
  --step-4:  clamp(2.07rem, 1.66rem + 2.05vw, 3.55rem);   /* display */
}
```

## Когда какая пара (быстрый ключ)

- Тёплый/женственный/уютный → TYP-001, TYP-008, TYP-010.
- Премиум/элегантный → TYP-002, TYP-003, TYP-005.
- Техно/чистый/B2B → TYP-004, TYP-007.
- Смелый/энергичный → TYP-006, TYP-009.
