# vite — CHANGELOG

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and SemVer.

## [2.1.0] — 2026-05-16

### Changed (Vite 6 → 7 bump; Vite 8 deliberately deferred)
- STACK_VERSIONS pin: `6.x` → `7.x`. **Vite 8.0.13 ships but is held back** — Vitest 4.1.1+ dropped Vite 8 beta support (Vitest 5 still in beta). Re-pin to 8.x once Vitest 5 reaches GA. Documented blocker in SKILL.md body and STACK_VERSIONS.md note.
- `SKILL.md` description: `Vite 6` → `Vite 7`; added `baseline-widely-available` and modernized-target keywords to trigger surface; added blocker note + Vite 6 → 7 migration call-out (Node 20.19+/22.12+ minimum, `splitVendorChunkPlugin` removed, Sass Legacy API removed, `transformIndexHtml` hooks use `order`/`handler`, `HotBroadcaster` and `experimental.skipSsrTransform` removed)
- `SKILL.md` Capabilities: clarified Environment API was introduced in Vite 6 and stabilized in Vite 7; added "Modernized browser defaults (Vite 7)" capability bullet (Chrome 107 / Edge 107 / Firefox 104 / Safari 16.0)
- `SKILL.md` Behavioral Traits: added Vite 7-specific guards (target audit vs new baseline, `{order, handler}` hook shape, `manualChunks` replacing `splitVendorChunkPlugin`)
- `references/REFERENCE.md`: header bumped to Vite 7.x + TS 6.0.x with blocker call-out
- `references/environment-api.md`: title bumped, restated that the surface is identical Vite 6 → 7 (no migration), doc URL `vitejs.dev` → `vite.dev`
- `references/performance.md`, `references/plugins.md`: noted that Vite 6 warm-cache and `this.environment` carry forward unchanged into Vite 7
- `references/eval-cases.md`: routing test updated to "Vite 7 environments"
- `references/{config-basics,library-mode,plugins,ssr-mode,troubleshooting,REFERENCE}.md`: top-level `# Vite 6 — ...` headings → `# Vite 7 — ...`
- `templates/vite.lib.config.ts.template`: `"vite": "^6.5.0"` → `"vite": "^7.0.0"`
- Inline `<!-- versions:start -->` block regenerated by `sync_skill_versions.py`

## [1.0.0] — 2026-05-15

### Added

- Initial release: full Vite 6 coverage per skill-evaluation v2
- `SKILL.md`: navigator with all sections — Use when, Do not use when, Purpose, Capabilities, Behavioral Traits, Important Constraints, Related Skills (90% filter), API Reference
- `references/REFERENCE.md`: decision map + quick patterns
- `references/config-basics.md`: defineConfig, root/base, resolve.alias, define, env vars, server.proxy, build options, HMR API, CSS, assets, Web Workers
- `references/plugins.md`: @vitejs/plugin-react (Babel + SWC), @vitejs/plugin-vue, @vitejs/plugin-svelte, full plugin authoring API, virtual modules, hot update
- `references/ssr-mode.md`: dev middleware (createServer + ssrLoadModule), vite-node, production SSR build, ssrManifest
- `references/library-mode.md`: build.lib, ES/CJS formats, externals, vite-plugin-dts, dual package.json exports, multi-entry
- `references/environment-api.md`: Vite 6 environments config, client/ssr envs, applyToEnvironment, migration from Vite 5
- `references/performance.md`: dep pre-bundling, manual chunks, build.target, source maps, minification, warm cache, bundle analysis
- `references/troubleshooting.md`: HMR failures, CJS/ESM errors, alias issues, env var debugging, base URL bugs, slow builds
- `references/eval-cases.md`: 15 positive routing tests, 9 negative tests, 5 edge cases, output behavior verification
- `templates/vite.config.ts`: React + Tailwind 4 production preset with {{placeholders}}
- `templates/vite.lib.config.ts`: Library mode preset with dual CJS/ESM output and package.json comment
- `examples/custom-plugin.md`: Full plugin with transform hook + virtual module + HMR invalidation
- `examples/multi-page-app.md`: Three-page MPA with shared chunks, HTML entries, dev server navigation
- Version block: Vite 6.x + TypeScript 5.9.x (managed by sync_skill_versions.py)
