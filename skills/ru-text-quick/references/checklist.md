# Чек-лист перед русской выдачей

Прогони ПЕРЕД тем, как отдать любой русский текст (даже одну строку).

## Anti-cliché

- [ ] Нет «качественный» → назови свойство или вычеркни
  _❌ «качественный код» → ✅ «код без ошибок линтера»_
- [ ] Нет «эффективный» → укажи метрику
  _❌ «эффективное решение» → ✅ «решение сократило время с 4 с до 0,8 с»_
- [ ] Нет «комплексный» → перечисли что включает
  _❌ «комплексная проверка» → ✅ «проверка подписи, идемпотентности и суммы»_
- [ ] Нет «успешно завершено» → просто «завершено»
  _❌ «задача успешно завершена» → ✅ «задача завершена»_
- [ ] Нет «в кратчайшие сроки» → назови срок
  _❌ «исправим в кратчайшие сроки» → ✅ «исправим до 15:00»_
- [ ] Нет «осуществляет / производит / данный» → конкретный глагол / «этот»
  _❌ «производит оплату» → ✅ «платит»_
- [ ] Нет «в рамках / на сегодняшний день / является» → упрости или вычеркни
  _❌ «является обязательным» → ✅ «обязательно»_

## Канцелярит

- [ ] Нет отглагольных существительных вместо глаголов
  _❌ «осуществление мониторинга» → ✅ «мониторинг» / «мониторю»_
- [ ] Цепочка родительных падежей не длиннее двух уровней
  _❌ «результат проверки корректности данных формы» → ✅ «форма прошла валидацию»_
- [ ] Нет пассивного залога без явного актора
  _❌ «тест был запущен» → ✅ «запустил тест» / «CI запустил тест»_
- [ ] Нет бюрократических формул
  _❌ «по результатам проведённого анализа установлено» → ✅ «анализ показал:»_
- [ ] Нет модальных смягчений
  _❌ «возможно, стоит рассмотреть» → ✅ «сделай X»_
- [ ] Нет тавтологий
  _❌ «свободная вакансия» → ✅ «вакансия»_

## Конкретика

- [ ] Числа вместо «много / быстро / долго / значительно»
  _❌ «долго выполняется» → ✅ «выполняется 14 секунд»_
- [ ] Перечисление вместо «ряд / некоторые / определённые»
  _❌ «ряд проблем» → ✅ «3 проблемы: X, Y, Z»_
- [ ] Нет расплывчатых прилагательных (соответствующий, определённый, надлежащий)
  _❌ «соответствующие меры» → ✅ «добавь проверку подписи»_

## Типографика

- [ ] Длинное тире `—` вместо дефиса `-` в предложениях
  _❌ «3 ошибки - все в auth» → ✅ «3 ошибки — все в auth»_
- [ ] Кавычки «ёлочки» вместо прямых "
  _❌ "найдено" → ✅ «найдено»_
- [ ] Многоточие `…` (один символ) вместо трёх точек `...`
  _❌ `...` → ✅ `…`_
- [ ] Неразрывный пробел между числом и единицей измерения
  _❌ `5 кг` (обычный пробел) → ✅ `5 кг` (неразрывный)_
- [ ] Диапазоны через en dash `–` без пробелов
  _❌ `10-15` → ✅ `10–15`_
