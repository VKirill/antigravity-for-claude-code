# Generation — `.generate()` API

`model.generate(...)` is the autoregressive decoding entry point for `AutoModelForCausalLM`, `AutoModelForSeq2SeqLM`, and VLM/ASR families.

## Basic call

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-7B-Instruct")
model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-7B-Instruct", dtype=torch.bfloat16, device_map="auto",
)

inputs = tok.apply_chat_template(
    [{"role": "user", "content": "Name three primes."}],
    add_generation_prompt=True, return_tensors="pt", return_dict=True,
).to(model.device)

with torch.inference_mode():
    out = model.generate(**inputs, max_new_tokens=64, do_sample=False)

# Slice off the prompt to get only new tokens:
new_tokens = out[0, inputs["input_ids"].shape[-1]:]
print(tok.decode(new_tokens, skip_special_tokens=True))
```

## Core kwargs

### Length

| Kwarg | Meaning |
|---|---|
| `max_new_tokens` | **prefer this** — cap on tokens generated after the prompt |
| `max_length` | total including prompt; do not use for new code |
| `min_new_tokens` | force at least N new tokens |

### Decoding strategy

| Kwarg | Effect |
|---|---|
| `do_sample=False` | greedy decoding (deterministic) |
| `do_sample=True` | sampling (then `temperature`, `top_p`, `top_k` apply) |
| `num_beams=N` | beam search; mutually exclusive with sampling |
| `num_beams=N, do_sample=True` | sampled beam search |
| `num_return_sequences=N` | return N candidates (sampling or beam) |

### Sampling knobs

| Kwarg | Range | Notes |
|---|---|---|
| `temperature` | (0, 2] | < 1 sharpens, > 1 flattens |
| `top_p` | (0, 1] | nucleus — keep smallest set summing to p |
| `top_k` | int | only top-k tokens are candidates |
| `min_p` | (0, 1) | drop tokens below `min_p * top_prob` (modern alternative) |
| `repetition_penalty` | ≥ 1.0 | > 1 discourages repeats |
| `no_repeat_ngram_size` | int | hard ban repeat n-grams |

### Stopping

| Kwarg | Notes |
|---|---|
| `eos_token_id` | scalar or list of token IDs that end generation |
| `pad_token_id` | needed for batched generation |
| `stopping_criteria` | custom `StoppingCriteriaList` for advanced cases |

### Caching

| Kwarg | Notes |
|---|---|
| `use_cache=True` | KV cache (default for inference; required for speed) |
| `cache_implementation` | `"dynamic"` (default), `"static"` (`torch.compile`-friendly), `"sliding_window"`, `"offloaded"` |

## `GenerationConfig` — reusable settings

```python
from transformers import GenerationConfig

gen_cfg = GenerationConfig(
    max_new_tokens=256,
    do_sample=True,
    temperature=0.7,
    top_p=0.9,
    repetition_penalty=1.05,
    eos_token_id=tok.eos_token_id,
    pad_token_id=tok.pad_token_id,
)

out = model.generate(**inputs, generation_config=gen_cfg)
```

Save with the model: `gen_cfg.save_pretrained(out_dir)` → reload via `GenerationConfig.from_pretrained(out_dir)`.

## Batched generation — `padding_side="left"`

```python
tok.padding_side = "left"
if tok.pad_token is None:
    tok.pad_token = tok.eos_token

prompts = ["Question 1?", "A longer question 2?", "Q3?"]
inputs = tok(prompts, return_tensors="pt", padding=True, truncation=True).to(model.device)

with torch.inference_mode():
    out = model.generate(**inputs, max_new_tokens=64, do_sample=False)

for row, prompt_ids in zip(out, inputs["input_ids"]):
    new_tokens = row[prompt_ids.shape[-1]:]
    print(tok.decode(new_tokens, skip_special_tokens=True))
```

Right-padding silently corrupts outputs for decoder-only models — always set `padding_side="left"` for batch generation.

## Streaming — `TextIteratorStreamer`

Stream tokens to the caller as they are generated by running `generate` on a background thread:

```python
from threading import Thread
from transformers import TextIteratorStreamer

streamer = TextIteratorStreamer(tok, skip_prompt=True, skip_special_tokens=True)

gen_kwargs = dict(
    **inputs,
    max_new_tokens=512,
    do_sample=True,
    temperature=0.7,
    streamer=streamer,
)

thread = Thread(target=model.generate, kwargs=gen_kwargs)
thread.start()

for chunk in streamer:
    print(chunk, end="", flush=True)

thread.join()
```

`TextStreamer` (non-iterator) prints directly to stdout — fine for CLIs, useless for servers.

## Stop sequences (custom)

```python
from transformers import StoppingCriteria, StoppingCriteriaList

class StopOnSubstring(StoppingCriteria):
    def __init__(self, tok, stop_str):
        self.tok = tok
        self.stop_str = stop_str
    def __call__(self, input_ids, scores, **kwargs):
        text = self.tok.decode(input_ids[0], skip_special_tokens=True)
        return text.endswith(self.stop_str)

out = model.generate(
    **inputs, max_new_tokens=512,
    stopping_criteria=StoppingCriteriaList([StopOnSubstring(tok, "</answer>")]),
)
```

## Determinism

```python
import torch, random, numpy as np

torch.manual_seed(42)
torch.cuda.manual_seed_all(42)
np.random.seed(42)
random.seed(42)

# Pair with do_sample=False for fully reproducible output
out = model.generate(**inputs, max_new_tokens=64, do_sample=False)
```

For tests, prefer `do_sample=False` — sampling masks systematic prompt-construction bugs.

## Generation gotchas

- Forgot `inference_mode` → autograd graph leaks; OOM on long contexts
- `max_length` used instead of `max_new_tokens` → output gets clipped if prompt was long
- Forgot `padding_side="left"` in batched call → some outputs corrupted
- `eos_token_id` mismatch between tokenizer and model → never stops
- Sampling at `temperature=0` → division-by-zero; use `do_sample=False` for greedy
